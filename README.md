# C# OOP Practice

Учебный проект, выполненный в процессе изучения C# и объектно-ориентированного программирования.

Задания и темы проекта основаны на методических материалах курса. Код написан в рамках самостоятельной практики и изучения возможностей языка C#.

## Что здесь изучается

* классы и объекты;
* наследование и полиморфизм;
* абстрактные классы;
* интерфейсы;
* generics;
* extension methods;
* пользовательские исключения;
* `enum` и `[Flags]`;
* LINQ;
* partial-классы;
* коллекции;
* поиск и фильтрация данных;
* экспорт данных в CSV и JSON.

## О проекте

В качестве одной из основных учебных моделей используется библиотечная система с книгами, журналами и каталогами.

Репозиторий предназначен для хранения моей учебной практики по C# и демонстрации тем, которые я проходил в ходе обучения.
